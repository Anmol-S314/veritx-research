MECS mechanics · one driver, passive taps

TOPO-003 §3, §9
Physical rule
  • ✓Exactly one electrical driver per channel segment per direction.
  • ✓Drop cells are passive: no arbitration, no queue, no path that stalls later taps.
  • ✓Multicast is one channel transaction with multiple simultaneous accepts; no replication logic.
Credit rule
drv_credit_ok = &(drop_credit | ~sel)

All selected drops must have staging room. One congested drop blocks the whole broadcast — measurable as TOPO_CNT_MCAST_BLOCK.

Pipeline & bypass

ROUTE-001 §9

ST0 · IN / RC

Latch flit into 2-flit staging. Lookahead route compute for the next hop runs in parallel.

ST1 · VA / SA

Three-level arbitration, credit check, crossbar select. Tightest path.

ST2 · ST / LT

Crossbar traversal and link traversal to the next router or drop interface.

Bypass path: when all conditions hold, ST0 drives ST2 directly and skips ST1 (1-cycle router latency). Nominal path is 2 cycles.

in_vld & rc_valid & out_idle[rc_port] & ~other_req[rc_port] & credit_avail[rc_port] & ~sidebuf_pending

The last term is a correctness requirement: a newer flit must not bypass an older buffered flit of the same flow. A side-buffer redirect is bounded by golden rotation, not by an unbounded queue.

Reference router: 12 route-compute instances, 2 allocators, 144 crosspoints × 512 b, 1 FIU path-selector per FIU.

Three-level arbitration

each level narrows
0
Level 0 · golden rotationIf a golden-window request is eligible, restrict to it; otherwise fall back to all eligible requests. Bounded-delay floor (F3).
1
Level 1 · slack classKeep the minimum slack class among survivors. 0 = critical … 3 = background.
2
Level 2 · STC batch epochKeep the minimum batch id among survivors; starvation bound (F4). RR breaks ties among the final set.
elig = req_vec & credit_avail & ~out_busy_mask
gnt_oh = rr_select(m2, rr_ptr)

One-hot grants avoid a decoder before the crossbar mux. out_busy_mask couples mesh and express stages; prec_first rotates precedence on the golden schedule.

A golden mask without the fallback would idle a cycle whenever no golden request exists. The fallback is a correctness requirement.

FIU FSM & flow-epoch cache

only adaptive state
IDLELOOKUPTEL_RDSELECTCACHEDINJECT
  • ✓LOOKUP probes the flow-epoch cache by flow hash; hit → CACHED, miss → TEL_RD.
  • ✓TEL_RD stalls on !tel_vld; Plane T is a TDM ring-tree with deterministic latency, so the stall is bounded. Stale congestion data is worse than no adaptivity.
  • ✓SELECT writes shape and Valiant intermediate into the cache. Re-randomising per packet breaks F6.
  • ✓INJECT holds the chosen shape while stalled on credit; it never re-evaluates on resume.
  • ✓Epoch expiry is lazy: compare an epoch tag, do not flush the whole cache at the boundary.
Hash collision: the second flow adopts the first flow’s cached shape and intermediate. It still reaches its destination and stays stable for the epoch; this is a performance failure, not a correctness failure.
Valiant rewrite: the router matching the cached intermediate rewrites the header shape to row-first and re-injects locally. It is the only place a router modifies a routing field.
Reset invalidates the cache and returns the FSM to IDLE. Configuration registers are not cleared by a data-plane reset.

Side-buffer control FSM

VC-002 §10
EMPTY · occ=0 FILLING · 0<occ<8 FULL · occ=8 2'b11 · illegal
  • ✓Drain is an action, not a state. Drain and fill may happen in the same cycle; modelling drain as a state would refuse losers unnecessarily.
  • ✓Drain-before-fill: occupancy is evaluated after the departing flit frees its slot, preventing a false overflow.
  • ✓Overflow is backpressure, not loss. Credit is withheld upstream; RAS containment is not invoked.
  • ✓Reset: state → EMPTY, occupancy → 0, tags invalidated, sb_rd_vld deasserted. Credit counters reset to maximum, never zero.
Write-port question: §11.2 defines one sb_wr_flit/sb_wr_port and do_fill = |alloc_loss. If two ports lose allocation in one cycle, the captured flit/tag is undefined. Either prove one loser per cycle or add a write arbiter and policy.
Capacity range 4–16 flits, default 8 (VC-R1). At 8 × 512 b the buffer is 4 Kbit: register file or latch array, not a single-port SRAM.

Credit accounting & alloc_loss

VC-002 §5–§6
Plane Dper drop2-flit staging window; upstream tracks every target drop.
Plane Cper VC4-flit depth; REQ/RSP/SNP counters independent.
D2Dpre-allocatedwindow sized to link RTT; UCIe owns calibration.
credit_avail[p] = (credit_cnt[p] != 0)
next_cnt = saturating(cnt − gnt + ret)

Simultaneous grant and return cancel exactly in one expression. The count stays in the credit manager; the allocator needs only availability, never quantity.

alloc_loss asserts only after a flit has failed in every stage eligible to serve it. Asserting on stage-1 loss alone causes spurious side-buffer captures, inflates occupancy and corrupts the Plane-T congestion hint. VC_CNT_SPURIOUS_FILL measures the early-loss fallback.
On reset, credit counters load cfg_max_credit. Resetting them to zero would deadlock the fabric at power-up.
