Subject: STRUCTURAL FIX: scripts/build_lock.sh — flock-based exclusive build lock (the OOM class is now enforced)

No lock mechanism existed ("builds-lock" was a one-off file convention). Added scripts/build_lock.sh:
- flock on /var/tmp/r1work/.build.lock (real disk); waits up to BUILD_LOCK_TIMEOUT (default 300s), fails fast with the holder's pid+cmd if exceeded
- pre-flight: fails immediately if verilator_bin or make -C *Vnoc_tb.mk is already running (catches non-script builds too)
- Usage: bash scripts/build_lock.sh <build cmd...>
- Verified: contender blocks while held, runs when free. GATE-R1-COORD rule 4 now points at it.
Please wrap future builds (verilator invocations) in it. This makes the "one build at a time" rule structural instead of a convention that keeps costing bisect rungs.
