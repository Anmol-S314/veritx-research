05 · Distributions

Population statistics for measured request metrics.

Percentiles are computed only from complete backend-provided per-request samples. Population, unit, domain and producer are stated on every statistic.

06 · Throughput / steady state

Separate warm-up, measurement window and drain.

Throughput and utilization metrics are shown only where the backend supplies them, with the measurement window named. Warm-up traffic is never mixed into steady-state metrics without a label.

07 · Causal analysis

Attribution over backend/evidence relationships.

Contributions are MEASURED, DERIVED-BY-BACKEND or UNMEASURABLE. The browser never estimates a missing contribution; it names the contract field that would be required.

08 · Critical path

Dependency path without invented classification.

Bottleneck labels appear only when a backend contract supplies them. Where only phase durations exist, durations are shown without a label.

09 · Overlap analysis

Communication / compute overlap from interval authority.

Overlap is computed only from backend-provided event intervals. Aggregate totals are never recombined into overlap metrics in the browser.

26 · Replay / diff

Staged comparison and first semantic divergence.

Stages: INPUTS → SERVING EXECUTION → COMMUNICATION → OUTPUT. Non-semantic runtime drift never counts as scientific divergence. Incompatible runs report INCOMPARABLE instead of deltas.

27 · Regression baselines

Gates a run must pass against a declared baseline.

Compatibility is evaluated before deltas. Gate thresholds come from the regression policy object, not UI code. Verdicts: NO REGRESSION, REGRESSION, INCOMPARABLE, UNMEASURABLE.

28 · Investigations

Debugging state that survives navigation and refresh.

Investigations are product state, not scientific authority. Pin requests, rounds, collectives, evidence and log entries; share a deep link; persist in localStorage.
