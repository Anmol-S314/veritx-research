 Injection Rate

 The injection rate is the average rate at which each node injects packets into the network, expressed
 as packets/node/cycle (or flits/node/cycle, depending on the simulator). It represents the offered
 network load.

        Low injection rate: Light traffic, minimal congestion.

        High injection rate: Heavy traffic, increased contention and congestion.

        As the injection rate approaches the network's capacity, latency rises sharply due to
         saturation.


 Latency (Cycles)

 Latency is the average number of clock cycles required for a packet to travel from its source node to its
 destination node.

 It includes:

        Router processing delay,

        Link traversal delay,

        Buffer waiting time,

        Contention due to network congestion.

 Lower latency indicates faster packet delivery and better network performance.



 Average Hop Count (Hops Avg)

 The average hop count is the mean number of routers (or links) traversed by packets from source to
 destination.

        Lower hop count generally reduces communication delay and dynamic network energy.

        Hop count depends primarily on the network topology and routing algorithm, rather than the
         traffic load.

 In Booksim, Hops Avg is commonly used as a NoC energy proxy, since communication energy is
 approximately proportional to the number of links and routers traversed.

Task5: Torus deadlock-safe routing check: use dim_order (torus-aware), NOT plain dor




 The Torus topology was configured with routing_function = dim_order, which is the torus-
 aware dimension-order routing algorithm. Unlike plain DOR, this implementation uses a dateline
 virtual-channel mechanism to break cyclic channel dependencies created by wrap-around links,
 ensuring deadlock-free packet routing.

 The topology was evaluated across the specified injection-rate sweep (0.002–0.03). The simulation
 completed successfully for all tested loads without hanging or reporting routing errors, indicating
 that the routing algorithm remained deadlock-free under the evaluated traffic conditions.

 dim_order executes successfully, whereas dor does not. This confirms that the Torus
 implementation in this Booksim build requires the torus-aware dimension-order routing function,
 which incorporates deadlock avoidance using the dateline virtual-channel mechanism. Plain DOR is
 unsupported for Torus in this implementation.


 A Torus forms a cyclic channel dependency because of its wraparound links. To eliminate deadlock,
 the routing algorithm introduces a logical dateline, which is a designated wraparound boundary
 rather than a physical cut. Whenever a packet crosses this boundary, it transitions to a higher-priority
 Virtual Channel (e.g., VC0 → VC1). Since packets are never allowed to transition back (VC1 → VC0),
 the channel dependency graph becomes acyclic, guaranteeing deadlock-free routing while preserving
 minimal paths.
Deadlock in Torus

A deadlock occurs when packets form a circular dependency, where each packet holds a channel or virtual
channel (VC) while waiting for another that is occupied by a different packet. Since no packet can progress, the
network reaches a permanent stall.

Dateline

A dateline is a logical boundary placed on one wraparound link of each torus dimension. It is not a physical cut in
the network, but a routing rule used to eliminate cyclic channel dependencies.

Virtual Channels (VCs)

A Virtual Channel (VC) is an independent logical buffer that shares the same physical link. When a packet crosses
the dateline, it is required to transition from VC0 to VC1. Since packets are not allowed to transition back from VC1
to VC0, the dependency graph becomes acyclic, guaranteeing deadlock-free routing.

Torus Dimension-Order Routing

In a Torus, Dimension-Order Routing (DOR) computes the minimum cyclic distance in each dimension, allowing
packets to use wraparound links when they provide a shorter path. Unlike Mesh routing, Torus DOR incorporates
dateline and Virtual Channel management to safely handle cyclic links while preserving deadlock freedom.
