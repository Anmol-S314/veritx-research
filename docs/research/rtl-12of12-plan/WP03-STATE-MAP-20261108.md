Snapshot: `rtl-12of12-release-v1` private copy (see evidence/snapshot-manifest.json).
Shared exporter: `CatalogExporter.scala` now requires **strict decrease**,
verified from the successor state (`hop.remaining == rule.remaining(successor)`

## WP03 decisions

- **Hybrid budget B removed.** Old `phase==remaining==B` + feasible-budget starts required exact-one. New measure is Manhattan distance; both native outcomes are legal at every unresolved-dimension state. Verified in Python: 1024 states (was 2048), 4864 vc-transitions, 304 resources (unchanged), first-hop union 1984/1984 vs dump, CDG acyclic, express -3 legal, equal/increasing/missing-link negatives rejected.
- **3-bit route tag NOT required; keep 2-bit.** Values needed: hybrid dimension 0..2 (2 bits), FlatFly order 1 bit, SROTA shape/stage 2 bits. Do NOT apply `tools/route_tag_3bit.patch`. If a future real feature needs 4..6, re-propose with test.
- **FlatFly/SROTA commitments:** structural equivalence documented (VC half / rank VC == catalog phase order). No real Constellation encoder exists yet (RouteComputer excludes route_tag) — forced-injection enforcement is WP11/WP12 production work, not claimed here. Union startStates remain as legal-relation coverage only.
- **Fly64 terminal caution:** `rule.terminal()` is router-based; Fly64 arrival is stage-2. Exporter keeps original `remaining==0 || !terminal` guard; only the exact-one check was relaxed to strict decrease. No other family needs regen (all already decrease by exactly 1, which satisfies strict).
- **Regen scope:** only `gec_hybrid` transitions/certificates need regeneration under new snapshot. All other 11 transitions are byte-identical by construction (their measures unchanged) — still verify with `check_routes.py` after Scala regen.
- **Credit note (for WP11):** OutputUnit `s.c` is free credit (resets to capacity, -alloc/+return, `credit_available = s.c!=0`). Native `GetUsedCredit` is occupancy (IQ `_next_buf Occupancy`, drop-form per-tap, port-form summed across taps). WP11 must derive used = capacity - free per VC, then aggregate per native port/drop rules; do not wire free count directly.
