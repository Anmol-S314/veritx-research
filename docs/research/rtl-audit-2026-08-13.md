## CRITICAL / BLOCKER

### F1 — Fork-copy XT collision: silent flit loss (`rtl/router.sv:281-324`)
The XT stage is written by TWO loops in the same always_ff:
- lines 281-292: one `xt_valid[o] / xt_flit[o]` write per SA pop (includes `o == PORT_L`
  for a genuine local eject);
- lines 303-324: the fork — writes `xt_valid[PORT_L] / xt_flit[PORT_L]` when a mcast
  head pops to a *network* port with `my_id` in `[copy_lo, copy_hi]`.

If a genuine local eject and a fork copy happen in the **same cycle at the same router**,
the fork loop's write clobbers the local eject: the eject flit was popped (credit returned
upstream, `hp` advanced) but never reaches the NIC — **silently lost**. The comment at
lines 300-302 ("can never collide … because the fork fires on a sa_pop to a NETWORK port")
is false: it only excludes the *same* sa_pop; a different `(i',v')` popping to PORT_L in
the same cycle is not excluded.

Second instance of the same bug: **two mcast heads popping at the same router in the same
cycle** — the fork loop writes `xt_valid[PORT_L]` twice; last write wins; **one copy lost**.
BookSim's fork pushes into a multi-entry output buffer, so it tolerates this; the RTL has a
single XT slot per port.

Exposure: NOT triggered by the current 2-die single-stream cells (fork routers have no
local eject traffic; streams are ~3800 cycles apart). **Guaranteed under any mixed-traffic
or multi-stream run** — i.e., the paper's own contention experiment (next steps #2) and
BigGPT's experiment C. Must be fixed before those runs: prioritize local eject over copy
and add a one-deep copy-hold register (defer the copy a cycle when the slot is busy).

### F2 — NIC reorder path leaves tptr on a mcast range word; replay stalls (`rtl/nic.sv:552-564`)
The `consumed1` reorder path (tptr+1 fires first, tptr defers) advances `tptr <= tptr + 2`
when the deferred entry finally fires (line 553). For a reorder-fired **mcast** entry, the
range word sits at `tptr+2` and is **never consumed** (the range-word skip at lines 561-564
only runs in the normal path and only checks `tptr+1`). The pointer then lands on the range
word; its `cycle==0` guard blocks firing *and* blocks advance (`tptr += 0`) → **NIC replay
deadlocks permanently**.

Worse, while the pointer sits on a range word, `c = trace_mem[tptr][31:24]` reads the
copy-lo field (e.g. `0x41` = 65) and is used to index `pkt[c]` / `last_vc[c]`
(lines 440, 457, 483) — **out-of-bounds reads** on `pkt[CLS=2]` / `last_vc[CLS]`
(UB in Verilator, garbage-dependent behavior).

Exposure: reorder requires two different-class entries due at the same tick; mcast adds
range words. The 15-cell sweep exercises reorder (cl0/cl1) but no mcast; the 2-die cell
exercises mcast but is all-class-0 → **the combination is untested and broken**. Fix:
latch "fired entry was mcast" in the reorder path and consume its range word on the
`consumed1` advance (and guard the `pkt[c]`/`last_vc[c]` reads against c ≥ CLS).

### F3 — Multi-flit multicast forks only the head (`rtl/router.sv:306`)
The fork fires on `front[i][v].mcast && front[i][v].head`. Body flits of a multi-flit
mcast stream pop without the mcast re-check → copies are 1-flit only. BookSim's fork
replicates **every flit** of the packet. Exposure: current cells are `packet_size=1`
(papers §4a/§4c setup) → untriggered. Any multi-flit KV row-multicast claim would be
wrong. Fix: keep an "in-mcast-range" per-VC flag from head to tail and fork on every pop,
or document the single-flit scope in the paper's threats.

## MODERATE

### F4 — `tb/noc_mcast_tb.sv` is stale and self-certifies
Uses `dst = 8'h83` with an undocumented "0x80 = multicast flag" encoding (line 67) and
never sets `flit.mcast/copy_lo/copy_hi`. On current RTL the flit routes to the east
boundary and is silently dropped; the TB prints "PASSED" unconditionally (line 90).
Must not be cited as evidence; either delete or rewrite against the flit_t fork encoding.

### F5 — 3D stack: latency model contradicts the gate contract
`mesh_3d.sv` wires routers **directly — no channel stage registers** (0-cycle links),
despite `noc_3d_pkg.sv` declaring `CH_LAT_2D=2, CH_LAT_3D=1` and the 2D gate contract's
2-stage links. `router_3d.sv` also: static (port-index-ordered) arbitration — no iSLIP /
RR parity; per-port 8-deep buffers instead of per-VC; `cred_free` increments unbounded
(no [0,8] saturation); silent flit drop when a port FIFO is full (no credit handshake);
`credit_out.vc` hardwired '0. It is a coarse functional model, not a cycle model — fine
as a sanity netlist, wrong as a timing oracle.

### F6 — `router_4d.sv` is a stub: no forwarding at all
Only reset + credit counting are implemented. `st`/`out_port`/`out_vc` are declared but
never driven; `flit_out`/`credit_out` never assert; `route_4d` (lines 29-44) is **never
called**. Any `mesh_4d` simulation delivers zero flits. Do not run, do not cite; either
implement or remove.

### F7 — fork 2-die TBs: duplicate module name, on-axis only
`tb/fork_2die_tb.sv` and `tb/fork_2die_tb2.sv` both define `module fork_2die_tb`
(compile conflict if both are in one build), and both test BRIDGE_ROW=0 (on-axis) only.
The paper's off-axis placement cell (T87/T117, 35-cycle penalty) has **no standalone TB**
in the tree — it is only claimed via the noc_tb sweep. Add an off-axis (BRIDGE_ROW=7)
unit test.

### F8 — Fork copies inject a phantom credit into the local port
The copy is written directly to the XT/`PORT_L` output — it never occupies the router's
local *input* buffer — but the NIC's `eject_credit` return for it lands in
`credit_free[PORT_L][vc]` (no matching decrement). The count drifts up to its [0,8]
saturation. Benign for gating (local output never stalls — NIC reads every cycle), but the
DBG5 audit predicate `cf + pops - acks == 8` (noc_tb.sv:280-286) fires for PORT_L on every
fork run. Audit line must subtract copy deliveries or exclude PORT_L.

## VERIFIED CLEAN

- **Credit accounting**: inc/dec net-zero same-cycle handling and [0,8] saturation
  (router.sv:438-453); NIC `free[]` same-cycle credit visibility and saturation
  (nic.sv:299-308); `cred_avail` same-cycle grant correctness.
- **VA/SA exclusivity**: `va_grab` vs `tail_rel` cannot collide on one (o,v)
  (router.sv:455-461); SA grants one winner per output (iSLIP, islip.sv).
- **Fork pid encoding** consistent end-to-end: nic stream pid = `(tptr+idx)<<4`
  (nic.sv:516); router copy pid = `stream_pid[15:4]<<4 | offset` (router.sv:316-317);
  rtl_r1.py diff maps stream = 32·ordinal ✓ (each mcast entry consumes entry+range).
- **Normal-path range-word consumption** (nic.sv:561-564) correct for the non-reorder case.
- **noc_2die.sv** (post b8531ac): credit lanes crossed correctly incl. early credits;
  flit paths A→B and B→A; port suppression (no duplicate path); 2-stage bridge channel.
- **tb/noc_tb.sv** (post b8531ac): replay_base ND scaling; all arrays ND*N-sized;
  drain break on `deje >= dinj + fdelta` with fdelta hoisted; dump format matches
  BookSim/rtl_r1.py.
- **mesh.sv / islip.sv / noc_pkg.sv**: wiring symmetric, boundaries terminated, no
  double-drive; single-iteration iSLIP with pointers advancing only on a match.
- **rt_mini.sv / rt2_mini.sv**: debug harnesses only; no correctness claims.
