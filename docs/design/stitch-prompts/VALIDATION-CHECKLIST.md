# Srota Studio — numbered coverage checklist

46 prompt targets: 45 surfaces/flows plus one missing-artifact state. A target can produce multiple frames; this is not an exact screenshot count.

Check an item after confirming its generated design exists. This does not establish review approval, implemented behavior, or hardware qualification. No items are prechecked; validate against your Stitch project.

Ranges: Design 01–09; Workloads & Requirements 10–15; Analysis 16–24; Explore 25–29; Verify 30–34; Deliver 35–39; Shared desktop 40–42; Optional agents 43–46.
