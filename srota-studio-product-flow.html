These are adapter responsibilities for the frontend, not claims about existing HTTP route names. Keep engine types behind the gateway and return frozen product views.

Frontend rule: render explicit engine states. Never infer PASS from missing values, never substitute 0 for absent metrics, and never recompute compiler-owned semantics in the browser.
